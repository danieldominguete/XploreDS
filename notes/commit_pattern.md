1) Instalar o commitzen
   
   `brew install commitizen`

2) Adicionar arquivos em stage

    `git add .`

3) Formatar commit

    `cz commit`

4) Ajustar versao

    `cz bump`

5) Gerar changelog

    `cz changelog`
